# Job-market-analyzer
## Overview
A Python project for exploring job listings stored in a CSV file.
The application filters records and calculates summary metrics
to answer basic questions about the dataset.

## Data Source
This project uses a synthetic dataset created for educational purposes.
Job listings and salaries are fictional and do not represent actual
openings or compensation at the companies listed.

The dataset is intended to demonstrate Python data processing and
analysis techniques, not to draw conclusions about the job market.

## Analysis Questions
- How many job listings are in the dataset?
- What is the average annual salary?
- Which listing has the highest salary?
- How are listings distributed by job title and experience level?
- Which listings match a location or skill?

## How to Run
1. Download main.py and job.csv into the same folder.
2. Open a terminal in that folder.
3. Run: python main.py
4. Select an option from the menu.

Requires Python 3. No additional packages are needed.

## Example Results
The included dataset contains 15 job listings:
- Average annual salary: $89,866.67
- Experience levels: 2 Entry, 4 Junior, 7 Mid, and 2 Senior

These results describe only the included dataset and should not
be interpreted as estimates of the overall job market.

## Skills Demonstrated
- Reading structured data with Python's csv module
- Filtering records by location, experience level, and skills
- Calculating averages and category counts
- Organizing reusable functions
